# Image Recognition

A machine learning image classification project comparing classical and neural-network-based models using scikit-learn.

This project implements and evaluates multiple supervised learning approaches for image recognition, including Gaussian Naive Bayes, K-Nearest Neighbors, and a Multi-Layer Perceptron classifier.

---

## Project Overview

The goal of this project is to classify images using different machine learning algorithms and compare their performance.

Models implemented:

- Gaussian Naive Bayes
- K-Nearest Neighbors
- Multi-Layer Perceptron

This project demonstrates how different model families approach image classification, ranging from probabilistic classifiers to distance-based methods and neural networks.

---

## Models Used

### Gaussian Naive Bayes

Gaussian Naive Bayes is a probabilistic classifier based on Bayes’ theorem. It assumes that features are conditionally independent and normally distributed.

### K-Nearest Neighbors

KNN classifies images based on the labels of the most similar training examples. It is simple, intuitive, and useful as a baseline for image recognition tasks.

### Multi-Layer Perceptron

The MLP model is a feedforward neural network that learns nonlinear relationships between image features and class labels.
